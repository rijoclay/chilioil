# Chilioil

Chilioil is a business venture project centered on product design and digital infrastructure. The project encompasses UI/UX design layouts and a structured database architecture built to support the product ecosystem.

## Project Overview

This repository contains the core design assets and database schema for the Chilioil product line. It serves as the single source of truth for the visual language and data structure of the platform.

## Tech Stack

- Database: SQL-based relational schema
- Design: Figma-compatible asset exports
- Assets: Product imagery and sequence frames

## Repository Structure

- `Sequence/` — Product and branding sequence frames (GIF source frames)

## Getting Started

Design assets in this repository are ready for handoff to development teams. Database schemas can be imported directly into your preferred SQL environment.
