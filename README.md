# Chilioil

Chilioil is an Indonesian D2C (Direct-to-Consumer) brand specializing in premium spicy chilli oil products. The brand operates a full-stack e-commerce platform that covers product browsing, online ordering, customer reviews, and promotional campaigns.

## Live Website

**https://allaboutchilioil.web.id/**

## Tech Stack

- Frontend: React (Lovable-generated SPA)
- Styling: Tailwind CSS
- Hosting: Cloudflare Pages / R2
- Analytics: Lovable-internal proxy

## Features

- **Shop** — Browse product catalogue with pricing and variants
- **Product Details** — Ingredients, nutrition, and product descriptions
- **Cart & Checkout** — Add to cart, order management
- **About Us** — Brand story and background
- **Contact** — Customer inquiries and support
- **Promo** — Discount campaigns and special offers
- **Reviews** — Verified customer testimonials and ratings

## Repository Structure

- `Sequence/` — Product and branding sequence frames (GIF source frames)
- `README.md` — Project documentation

## Getting Started

This repository contains the design assets, branding materials, and database infrastructure documentation for the Chilioil platform. The live website is deployed separately on Cloudflare Pages.
